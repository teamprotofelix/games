# 🎮 혜담 · 아림을 위한 신나는 게임월드

기존 16개 미니게임을 유지하면서 **스마트폰용 신규 아케이드 5개**를 추가한 21종 게임 컬렉션입니다. 정적 파일만으로 실행되므로 GitHub Pages에서 별도의 서버, 회원가입, API 키, 빌드 과정이 필요하지 않습니다.

## ✨ 2026 신규 아케이드 (5종)

| 게임 | 게임성 | 모바일 조작 | 종료 조건 |
| --- | --- | --- | --- |
| 🦊 달빛 숲 점프 | 점프하며 가시 회피, 별 수집, 점점 빨라지는 질주 | 화면 터치 / 점프 버튼 | 50초 또는 체력 0 |

| 🌸 꽃잎 비트 정원 | 3레인 타이밍, PERFECT 판정, 콤보 | 레인 터치 / 3개 버튼 | 48초 |

| 🍬 솜사탕 타워 | 움직이는 블록의 겹침을 계산해 타이밍 쌓기 | 터치 / 내려놓기 버튼 | 60초 또는 3회 실패 또는 12층 완성 |

각 게임에서 모바일 큰 버튼 외에 키보드 조작을 지원합니다. 브라우저 내 최고 점수는 로컬 저장소(`localStorage`)에 보관됩니다.

## 🧸 기존 미니게임 (16종 유지)

두더지 잡기, 카드 짝맞추기, 별 받기, 가위바위보, 스네이크, 수학 퀴즈, 2048 퍼즐, 벌레 잡기, 틱택토, 반응 속도, 숫자 야구, 색깔 맞추기, 버블 팝, 슬라이드 퍼즐, 순발력 탭, 사이먼 기억력.

기존 JS 게임 로직과 CNAME은 삭제하지 않았습니다. 신작은 독립 파일 `js/adventures.js`에 구현했습니다.

## 🖼️ 이미지와 용량

- 신작 배경 **5장**: `images/adventure/{forest,ocean,garden,cosmos,candy}.webp` — **1280×720px**
- 캐릭터·아이템 스프라이트 **5장**: `fox-run.webp`(224×224px × 4프레임), `submarine.webp`, `pearl.webp`, `jelly.webp`, `flowers.webp`(176×178px × 4프레임)
- 썸네일 **5장**: `thumb-*.webp` — **720×405px**
- 메인 배너 **1장**: `hero-world.webp` — **1280×520px**
- 전체 신작 배경·스프라이트·메인 배너는 WebP입니다. 기존 로고 PNG/JPG는 호환을 위해 보존했습니다. 홈 화면 아이콘만 PWA 호환을 위해 PNG로 제공됩니다.

이미지는 독립 제작한 벡터풍 일러스트레이션을 고해상도로 렌더링하고 WebP로 변환했으며, 외부 이미지를 무단 복제하지 않았습니다. 런타임에서 신규 캐릭터 스프라이트는 명확히 고정된 프레임 크기로만 잘라 사용합니다.

## 배포

1. 이 ZIP의 **`index.html`, `css/`, `js/`, `images/`, `manifest.webmanifest`, `sw.js`, `CNAME`** 등이 루트에 놓이도록 저장소 `main`에 업로드합니다.
2. GitHub 저장소의 Settings → Pages에서 **Deploy from a branch**, `main` + `/ (root)`을 선택합니다.
3. HTTPS 운영 도메인에서 접속하면 PWA용 서비스 워커가 동작하며, 홈 화면에 추가하면 설치형 앱처럼 실행할 수 있습니다. `file://`로 열 때도 게임은 실행되지만 서비스 워커는 등록되지 않습니다.
4. 배포 후 기존 서비스 워커 업데이트를 위해 웹페이지 새로고침을 한 번 권장합니다.

`CNAME`은 기존 운영 도메인 값을 그대로 유지합니다. 모든 게임 처리와 결과 저장은 브라우저 안에서 이뤄지며 외부 서버나 키를 요구하지 않습니다.

## 구조

```text
index.html                   사이트 및 게임 메뉴
css/style.css                반응형 메뉴·게임 화면
js/script.js                 원본 16개 게임 + 게임 선택 컨트롤러
js/adventures.js             신규 5개 캔버스 게임
images/adventure/*.webp      신규 배경·썸네일·스프라이트
images/                      기존 로고 + PWA 아이콘
manifest.webmanifest         홈 화면 설치 정보
sw.js                        동일 출처 게임 리소스 오프라인 캐시
CNAME                        기존 도메인 유지
VALIDATION.md                검사 결과·제약 사항
```
